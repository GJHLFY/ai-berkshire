## 逐条检验

### ① 10年平均ROE：✅ 33.7%（阈值 <8%）

| FY | ROE | 备注 |
|----|-----|------|
| 2017 | 34.2% | |
| 2018 | 19.7% | 受《减税与就业法案》一次性费用影响 |
| 2019 | 44.6% | |
| 2020 | 31.5% | COVID冲击 |
| 2021 | 44.9% | 峰值年 |
| 2022 | 39.6% | |
| 2023 | 36.2% | |
| 2024 | 39.5% | |
| 2025 | 24.4% | 转型期，利润下滑 |
| 2026 | ~22.1% | 估计值（NI $3,108M / 均权益 ~$14,060M） |
| **均值** | **33.7%** | |

**判断**：即使在最差的 FY2018（税改冲击）和近两年转型低谷，ROE 仍维持在 20% 以上。10年均值 33.7%，远超 8% 排除线。这是顶级消费品牌的资本回报特征。

> 巴菲特："我们最喜欢的企业是那些拥有高且稳定的净资产回报率的企业。"Nike 做到了。

**但另一方面**：ROE 近两年从 40%+ 骤降至 ~22%，反映利润压缩和转型阵痛。如果当前趋势持续，10年均值将逐步下行。

### ② 5年累计自由现金流：✅ ~$198亿（阈值：为负排除）

| FY | 经营现金流 | 资本开支 | 自由现金流 |
|----|-----------|---------|-----------|
| 2022 | $5,188M | -$758M | **$4,430M** |
| 2023 | $5,841M | -$969M | **$4,872M** |
| 2024 | $7,429M | -$812M | **$6,617M** |
| 2025 | $3,698M | -$430M | **$3,268M** |
| 2026 | ~$1,231M（估计） | ~-$546M（估计，9个月Q1-Q3） | **~$685M**（估计） |
| **累计** | **~$23,387M** | **~-$3,515M** | **~$19,872M** |

**判断**：5年累计 FCF 接近 $200亿，是真金白银的现金牛企业。FY2026 FCF 骤降至 ~$7亿（Ainvest 估算约 $10.5亿），同比下滑 68-80%，但仍是正数。

> 芒格："我从来没见过一家企业长期没有自由现金流还能成为伟大的公司。"

**但另一方面**：FY2026 自由现金流崩塌式下降是一个值得警惕的信号。若 FY2027 仍未恢复，需重新评估现金流健康度。Ainvest 分析称这是"结构性红旗而非暂时性波动"（2026年7月）。

### ③ 利息覆盖倍数：✅ 24.5x（阈值 <2倍）

| 项目 | FY2026 | FY2025 |
|------|--------|--------|
| EBIT（营业利润） | **$3,797M** | $3,702M |
| 利息费用总额（估计） | **~$155M** | ~$297M |
| 利息收入 | ~$205M | ~$404M |
| **净利息（收入）/费用** | **$(50M)**（净收入） | $(107M)（净收入） |
| **覆盖倍数** | **24.5x** | 12.5x |

**判断**：Nike 非但没有利息负担，而且是**净利息收入**状态——利息收入大于利息支出。总债务 ~$110亿，现金 ~$76亿，净债务仅 ~$35亿。资产负债表的债权人风险极低。

**但另一方面**：FY2026 总债务中 $20亿将在12个月内到期（从长期债转为流动负债），需关注再融资节奏。

### ④ 长期毛利率：✅ ~44.1%（阈值 <15%）

| FY | 毛利率 |
|----|--------|
| 2017 | 44.6% |
| 2018 | 43.8% |
| 2019 | 44.7% |
| 2020 | 43.4% |
| 2021 | 44.8% |
| 2022 | 46.0% |
| 2023 | 43.5% |
| 2024 | 44.6% |
| 2025 | 42.7% |
| 2026 | 42.9%（含IEEPA关税回收210bps） |
| **均值** | **~44.1%** |

**判断**：10年毛利率在 42-46% 窄幅波动，是品牌护城河的教科书级证据。全球运动品牌中，Nike 毛利率长期领先 Adidas（~50%但含零售）、Lululemon（~58%但规模小得多）、安踏（~63%含中高端）。

⚠️ **重要提示**：FY2026 的 42.9% 包含了 210bps 的 IEEPA 关税回收收益。**剔除该一次性因素，FY2026 基础毛利率约 40.8%**，呈下行趋势。10年均值用基础毛利率重算约 43.9%，仍远高于 15% 排除线。

> 段永平："毛利率高说明你有定价权，定价权是护城河最重要的体现。"

**但另一方面**：毛利率趋势在下行——从 FY2022 的 46.0% 高点降至 FY2026 基础 40.8%，下滑超过 500bps。这是客单价压力、渠道结构调整（DTC → 批发回流）和促销增加的综合结果。

### ⑤ 经营现金流 / 净利润（5年均值）：✅ ~0.97（阈值 <0.7）

| FY | OCF | NI | OCF/NI |
|----|-----|-----|--------|
| 2022 | $5,188M | $6,046M | 0.86 |
| 2023 | $5,841M | $5,070M | 1.15 |
| 2024 | $7,429M | $5,700M | 1.30 |
| 2025 | $3,698M | $3,219M | 1.15 |
| 2026 | ~$1,231M（估计） | $3,108M | **~0.40**（估计） |
| **均值** | | | **~0.97** |

**判断**：FY2017-FY2025 累计 OCF 远超累计 NI，利润质量高。FY2022-FY2024 每年 OCF/NI 均 >1.0，说明利润不是"纸面富贵"。

⚠️ **FY2026 异常**：OCF/NI 骤降至 ~0.40，远低于历史水平。这可能是库存积压、应收账款周期延长，或 Q4 现金流季节性偏弱所致。若全年 OCF 最终高于当前估计（例如 Ainvest 的 TTM ~$16亿估算），比率将回升至 ~0.50-0.55，但仍是多年来最低。

**但另一方面**：如果 FY2027 OCF/NI 继续低于 0.7，这个指标将从"通过"变为"需要警惕"。

| 时间点 | 稀释加权平均股数 |
|--------|-----------------|
| FY2021 | **1,609M** |
| FY2022 | 1,611M |
| FY2023 | 1,570M |
| FY2024 | 1,530M |
| FY2025 | 1,488M |
| FY2026 | **~1,482M**（估计） |
| **5年变化** | **(1,482 - 1,609) / 1,609 = -7.9%** |

**判断**：Nike 持续大规模回购，5年缩减股本近 8%。管理层在回报股东方面行动一致。

**但另一方面**：EPS $2.10 中约 -0.4% 的"增长"来自于股本缩减而非利润增长。在利润下滑期（FY2026 NI -3% YoY），回购对 EPS 的支撑有限。

## 综合结论

### Nike 通过去劣筛选（7/7 ✅）

Nike 在全部七条指标上均远超排除阈值，不存在任何"边界争议"。即便在 FY2025-2026 的转型低谷期，所有指标仍然安全高于排除线。

**但这不等于 Nike 当前值得投资。**通过去劣筛选只说明"不是一流以下"，不说明"现在该买"。需要进一步研究以下关键问题：

| 维度 | 待研究问题 |
|------|-----------|
| **商业模式** | DTC → 批发回流的战略逆转，是否损害品牌溢价和长期毛利率？ |
| **竞争格局** | On、Hoka、lululemon、安踏等侵蚀份额的速度和天花板？ |
| **管理层** | Elliott Hill 回归 CEO 后的执行力？新战略何时能在收入端见效？ |
| **现金流** | FY2026 FCF 崩塌是一次性的还是结构性的？库存和应收账款周期是否在恶化？ |
| **估值** | $71 对应 ~25x FY2026 PE（NI $3,108M），在利润下行期是否合理？ |
| **催化剂** | 2026 世界杯、2028 洛杉矶奥运会能否驱动新一轮增长周期？ |

> 段永平："看懂一家公司比看懂它的财报难得多。财报能排除坏公司，但不能帮你在好公司里挑最好的。"
